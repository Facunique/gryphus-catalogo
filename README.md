# Gryphus — Catálogo 3D

Catálogo de Gryphus armado como una habitación home office en 3D: macetas, tótems y tags NFC, Mesa Viva, soportes de auriculares y de celular, reparación de notebooks e impresión 3D a pedido.

Tocá un producto y el cóndor te lleva hasta él. Tirá del hilo del foco para cambiar entre modo claro y oscuro.

**Ver el sitio:** https://facunique.github.io/gryphus-catalogo/

Sitio estático con [Three.js](https://threejs.org). Para verlo en local:

```bash
python3 -m http.server 8000
```
